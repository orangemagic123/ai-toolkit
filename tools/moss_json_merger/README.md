# MOSS JSON 태그 결합기

Windows 실행 파일 `MOSS_JSON_Merger.exe`를 더블클릭합니다. 실행 파일에는 Python과 Tk가 포함되어 있어 Python, ai-toolkit, llama 서버를 따로 실행할 필요가 없습니다.

## 사용

1. **MOSS JSON 폴더**와 **태그 TXT 폴더**를 선택합니다. 두 폴더가 같아도 됩니다.
2. `001.json`과 `001.txt`처럼 같은 상대 경로와 같은 이름의 파일이 연결됩니다. 하위 폴더를 포함할 수 있습니다.
3. 기본 보호 구분자는 `|||`입니다. `1girl, char, artist ||| apple, solo, red eyes`는 다음으로 변환됩니다.

```json
"keep_tags": ["1girl", "char", "artist"],
"tags": ["apple", "solo", "red eyes"]
```

4. **검사 / 미리보기**를 누르고 표에서 파일을 선택해 결과를 확인합니다. 첫 번째 열의 체크 표시 또는 스페이스 키로 적용 대상을 바꿀 수 있습니다.
5. **선택한 항목 결합**을 누릅니다. 자연어 캡션과 기타 JSON 필드는 그대로 보존됩니다.

함께 제공하는 `examples/json`과 `examples/tags` 폴더로 먼저 사용해 볼 수 있습니다. 이미지 파일 없이도 결합할 수 있습니다. 창 크기를 조절하거나 최대화하면 긴 태그와 자연어를 더 넓게 볼 수 있습니다.

기존 태그의 기본 정책은 **합치기**입니다. 기존 항목 뒤에 새 항목을 추가하고, 중복을 없애며, 보호 태그와 겹치는 일반 태그를 제외합니다. 기존 보호 태그 → 공통 보호 태그 → TXT 보호 태그 순서를 유지합니다. TXT에서 지운 태그를 결과에서도 제거하려면 **TXT 기준 교체**를 선택합니다. **빈 필드만 채우기**도 지원합니다.

구분자가 없으면 TXT 전체를 일반 태그로 가져옵니다. 구분자가 두 번 이상 나오거나 TXT가 비어 있으면 오류로 표시합니다. 기본 UTF-8/BOM 외에 한국어 CP949를 직접 선택할 수 있습니다. 여러 줄이 하나의 태그 목록인 경우에만 **줄바꿈도 태그 구분자로 사용**을 켭니다. `;;;` 같은 그룹 표기는 문자열 그대로 보존합니다.

## 저장과 백업

- **원본 JSON 갱신 + 자동 백업**: 이미지 옆 JSON을 갱신합니다. 바꾸기 전 파일을 JSON 폴더의 `_moss_merge_runs/실행시간/backups/` 아래에 같은 하위 경로로 백업합니다.
- **별도 폴더에 JSON만 출력**: 입력은 수정하지 않습니다. 이미 다른 내용의 출력 파일이 있으면 덮어쓰지 않고 표시합니다. 학습할 때에는 최종 JSON을 대응 이미지와 함께 배치해야 합니다.
- 미리보기 이후 JSON/TXT가 바뀌면 해당 항목을 건너뜁니다. 다시 검사하면 최신 내용으로 계획을 만들 수 있습니다.
- 동일한 결과는 다시 저장하지 않습니다. 반복 실행해도 중복 태그가 늘어나지 않습니다.
- **취소**는 현재 파일 처리를 마친 뒤 적용됩니다. 저장한 파일은 유지하며 나머지를 취소로 기록합니다.
- **보고서 폴더 열기**에서 `report.csv`와 `summary.json`을 확인할 수 있습니다. CSV는 Excel에서 한글을 읽을 수 있도록 UTF-8 BOM으로 저장합니다.
- 수동 복원 시 `backups/`의 JSON을 원래 상대 경로에 복사하면 됩니다. 이후 따로 수정한 파일이 있다면 내용을 먼저 비교해 주세요.

현재 ComfyUI 캡션 워크플로우가 저장하는 TXT는 자연어일 수 있습니다. 태그 TXT 폴더에는 실제 태그 파일을 지정해 주세요. 이 프로그램은 파일 내용만으로 자연어와 태그의 의미를 판단하지 않습니다.

캡션에 이미 포함된 워터마크 서술과 TXT의 워터마크 관련 태그도 그대로 보존합니다. 워터마크를 자동으로 판별하거나 캡션에서 제거하는 기능은 포함되어 있지 않습니다.

## 소스 실행 / 빌드

소스 버전은 Python 3.10 이상과 Tkinter로 동작합니다. 이 폴더의 `MOSS_JSON_Merger.pyw`를 더블클릭하거나 `python app.py`로 실행합니다.

```powershell
python app.py --json-dir C:\dataset\json --txt-dir C:\dataset\tags
```

Windows 실행 파일 재빌드는 PyInstaller가 설치된 Python에서 `Build-Windows.ps1`을 실행합니다. 생성 위치는 저장소의 `output/moss_json_merger/MOSS_JSON_Merger.exe`입니다.

short/medium/long은 모두 JSON에 보존합니다. 길이별 선택 비율은 ai-toolkit 학습 설정에서 지정합니다.
